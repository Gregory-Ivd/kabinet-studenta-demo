# Кабінет студента: демонстрація

Статична сторінка про навчальний проєкт Smart Attic Team: як зміни в розкладі потрапляють до календаря Moodle
(таблиця, стрічка iCalendar, сім текстових статусів). Дані на сторінці вигадані.

Відкрити: https://gregory-ivd.github.io/kabinet-studenta-demo/

Без збірки й залежностей: один файл `index.html`. Нічого нікуди не надсилає.
